🚀 Django Web Project
📌 Project Overview

This is a Django-based web application developed to manage and display structured content such as categories, cities, news, sliders, and user-related data. The project follows standard Django architecture with static files, templates, and modular apps.

⚙️ Installation & Setup
1️⃣ Clone Repository
git clone https://github.com/your-username/your-repo-name.git

2️⃣ Go to Project Folder
cd mydjangoproject

3️⃣ Create Virtual Environment
python -m venv venv

4️⃣ Activate Virtual Environment

Windows:

venv\Scripts\activate


Mac/Linux:

source venv/bin/activate

5️⃣ Install Requirements
pip install -r requirements.txt

6️⃣ Run Migrations
python manage.py migrate

7️⃣ Run Server
python manage.py runserver
